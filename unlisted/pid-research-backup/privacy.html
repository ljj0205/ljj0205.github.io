PID Research Backup · 시행일 2026년 10월 17일

PID Research Backup은 계정 소유자가 개인 연구용 해석 결과를 자신의 Google Drive에 백업하기 위해 운영하는 도구입니다. 이 방침은 이 백업 도구의 Google 계정 및 연구 파일 처리에 적용됩니다.

1. 접근하는 정보와 이용 목적

승인한 계정인지 확인하기 위해 Google 계정 이메일을 조회합니다. 백업 위치 조회, 업로드, 업로드 확인과 복구 위치 기록을 위해 지정된 연구 파일의 내용, 파일명, 폴더 정보, 파일 식별자, 크기, 수정시각과 체크섬을 처리합니다.

2. Google 권한의 범위

기존 연구 백업 폴더를 이용하기 위해 Google Drive 파일 접근 권한을 요청합니다. 이 권한은 Google 계정 수준에서 넓은 파일 접근을 허용할 수 있습니다. 실제 백업 실행은 설정에 지정된 연구 백업 폴더와 명시된 파일 목록을 대상으로 합니다. 권한은 Google의 동의 화면에서 계정 소유자가 승인합니다.

3. 저장 위치와 보호

백업 파일은 계정 소유자의 Google Drive에 저장됩니다. OAuth 인증 정보는 승인된 작업 컴퓨터의 접근을 제한한 설정 파일에 보관됩니다. 작업 컴퓨터에는 파일 식별자, 백업 경로, 파일 크기, 체크섬과 완료시각 등 백업 확인 기록을 보관합니다.

4. 외부 제공과 데이터 이용

파일 전송과 보관 과정에서 Google Drive 서비스가 데이터를 처리합니다. 이 도구는 Google 사용자 데이터를 판매하거나 광고에 이용하지 않으며, 범용 인공지능 모델 학습에 이용하지 않습니다. 백업 도구의 Google API 데이터 이용 및 다른 앱으로의 이전은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다.

5. 보관, 삭제와 권한 철회

백업 파일과 작업 기록은 계정 소유자가 연구 보관 목적으로 관리합니다. 백업 확인 후 로컬 중복 파일을 정리하는 작업은 별도 저장공간 관리 절차로 수행됩니다. Google Drive에 저장된 파일은 계정 소유자가 Drive에서 관리하거나 삭제할 수 있습니다.

Google 계정의 서드 파티 연결 설정에서 이 앱의 접근 권한을 철회할 수 있습니다. 권한을 철회하면 이후 접근과 백업이 중단됩니다. 이미 저장된 Drive 파일과 로컬 기록은 별도로 삭제할 때까지 유지됩니다.

6. 소개 웹사이트

이 소개 웹사이트는 정적 안내 페이지입니다. 페이지 자체에는 로그인 양식, 파일 업로드 기능이나 별도의 방문 분석 코드를 넣지 않습니다. 웹 호스팅 사업자는 서비스 운영을 위한 일반적인 접속 기록을 처리할 수 있습니다.

7. 문의와 변경

개인 연구용으로 운영합니다. 계정 및 접근 권한에 관한 문의는 Google 동의 화면에 표시되는 앱 지원 이메일로 연락해 주세요.
